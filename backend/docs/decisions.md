# Архитектурные решения бэкенда

| Решение | Почему | Что дальше |
|---|---|---|
| Деньги хранятся целыми в тиынах, наружу отдаются в тенге | нет ошибок округления float | без изменений |
| SQLite по умолчанию, PostgreSQL через `DATABASE_URL` | запуск без установки сервера, быстрые тесты | проверить на PostgreSQL |
| `create_all` при старте вместо Alembic | схема ещё меняется, один день на каркас | подключить Alembic до первой реальной БД |
| Модель прогноза `fc-1.0-bootstrap`: выборка из собственных дневных трат по дням недели | объяснима, не требует обучения, хватает 3–4 месяцев данных | сравнить с наивным базовым прогнозом на отложенной выборке (план оценки) |
| Общие случайные числа для базы и сценария | разница сценария не зашумлена случайностью | без изменений |
| `p_shortfall` = доля траекторий, где баланс хоть раз ниже 0 за горизонт | прямое определение вероятности кассового разрыва | валидация по CFPB Financial Well-Being Scale |
| Веса индекса: разрыв .25, подушка .25, DTI .20, волатильность .10, стабильность дохода .10, доля валюты .10 | экспертная стартовая оценка | калибровка по опросу |
| Импорт демо идёт через синтетический парсер и настоящий пайплайн | проверяет дедупликацию и категоризацию без реальных выписок | парсер Kaspi PDF |
| Макро и цены по городам помечены `demo-seed` | нет автоматического источника, НБ РК не отдаёт всё в одном API | загрузка курсов из XML НБ РК (`parse_nbk_rates` готов), CPI из бюллетеней БНС |
| Ошибки в формате `application/problem+json` | фронтенд читает `detail`, затем `title` | без изменений |

## Дополнения к docs/api-requests.md фронтенда
- `POST /auth/register`, `POST /auth/login`, `GET/PATCH/DELETE /me`: сейчас фронтенд использует мок-авторизацию, нужно подключить. Токен возвращается в теле (`Authorization: Bearer`), httpOnly cookie пока нет.
- `DELETE /obligations/{id}`.
- `POST /imports`: JSON `{"bank": "..."}` запускает демо-импорт; multipart с полями `bank` и `file` пока отвечает 501.
- `POST /scenarios/run` принимает `days`.
- `GET /obligations/dti-history` реализован.
