# Backend: прогноз финансовой устойчивости

FastAPI-сервис для веб-платформы прогнозирования персональной финансовой устойчивости (Казахстан, 22–45 лет).
Контракт API совпадает с фронтендом (`src/api/types.ts`, `client.ts`), все пути под `/api/v1`.

## Что реально работает
- Импорт выписок Kaspi Gold и Freedom Bank (PDF) и демо-импорт: единый пайплайн (дедупликация, категоризация по ключевым словам и правилам пользователя, поиск переводов между своими счетами, поиск регулярных платежей и доходов).
- Прогноз: Монте-Карло на основе собственных трат пользователя (bootstrap по дням недели), известные потоки (доходы, обязательства), перцентили p10–p90, вероятность кассового разрыва.
- Индекс устойчивости 0–100 из пяти компонентов; сценарии (курс, инфляция, доход, потеря работы) на тех же случайных траекториях.
- Личная инфляция: официальный CPI, взвешенный по структуре трат пользователя.
- Правила-инсайты, цели, обязательства, календарь платежей, DTI по месяцам.

## Что демо или не реализовано
| Часть | Статус |
|---|---|
| Данные пользователя `demo@zapas.kz` | синтетические, идут через настоящий пайплайн импорта |
| Макро-ряды и цены по городам | `demo-seed`; только курс USD/KZT 452,59 на 20.10.2026 взят с сайта НБ РК, остальное интерполяция |
| История индекса устойчивости | `demo-seed` для прошлых месяцев |
| Разбор PDF | Kaspi Gold (945 операций) и Freedom Bank (9 операций) проверены на реальных выписках, итоги совпали с банком; банк определяется по самому PDF, имя из формы только запасной вариант; Halyk в отдельной ветке |
| Alembic | нет, таблицы создаются `create_all` (см. docs/decisions.md) |
| PostgreSQL | драйвер в зависимостях, не проверялся |

## Запуск
```bash
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env
uvicorn app.main:app --reload     # при первом старте создаёт БД и сид
```
Документация API: http://localhost:8000/docs. Демо-вход: `demo@zapas.kz` / `demo1234`.
Пересоздать сид: удалить `data/app.db` и перезапустить (или `python -m app.seed`).

Фронтенд: `VITE_API_MODE=real` и `VITE_API_URL=http://localhost:8000/api/v1`.

## Проверка
```bash
pytest -q      # 33 теста: категоризация, движки, API
ruff check .
```
Тесты используют временную SQLite, дату `APP_AS_OF=2026-10-20` и 600 траекторий.
