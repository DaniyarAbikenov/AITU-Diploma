# Система прогнозирования персональной финансовой устойчивости

> Дипломный проект: «Разработка системы прогнозирования персональной финансовой устойчивости на основе анализа денежных потоков и макроэкономических показателей».

**Автор:** Данияр Абикенов (GitHub: DaniyarAbikenov) · **Научный руководитель:** Эльвира Айтмуханбетова
**Статус:** предзащита, этап 1 (24.10.2026). Работает бэкенд-прототип с демо-данными, фронтенд-прототип в отдельном репозитории.

## Описание
Веб-платформа, которая по денежным потокам пользователя и макропоказателям Казахстана оценивает, насколько он устойчив к финансовым шокам: считает вероятность кассового разрыва в ближайшие 90 дней, запас в месяцах при потере дохода и индекс устойчивости 0–100.

## Проблема
Существующие приложения показывают прошлые траты, но не отвечают на вопрос «хватит ли мне денег и что будет, если курс вырастет или пропадёт доход». По интервью с 6 респондентами пользователям нужны прогноз остатка к концу месяца, предупреждение о разрыве, видимая долговая нагрузка и сравнение с прошлыми месяцами. Анализ: [docs/research](docs/research).

## Пользователи
Люди 22–45 лет в Казахстане с регулярным доходом, кредитами или рассрочками и тратами, частично привязанными к курсу доллара.

## Ожидаемые результаты
- Прогноз баланса и конца месяца с интервалом неопределённости (Монте-Карло).
- Индекс устойчивости с объяснением компонентов, сценарии «что если».
- Личная инфляция по структуре трат, макроконтекст по Казахстану.
- План оценки: метрики качества прогноза и валидация по шкале CFPB Financial Well-Being.

## Границы проекта
**В объёме:** импорт выписок, категоризация, прогноз, индекс устойчивости, сценарии, макропоказатели, цели.
**Вне объёма:** платёжные операции, инвестиционные советы, интеграция напрямую с банками, обучение финансовой грамотности как основная функция.

## Технологии
Бэкенд: Python 3.13, FastAPI, SQLAlchemy 2, SQLite (PostgreSQL через `DATABASE_URL`), numpy, pytest. Фронтенд: React, TypeScript, TanStack, ECharts (папка `frontend/`).

## Запуск и проверка
Подробно в [backend/README.md](backend/README.md):
```bash
cd backend && pip install -r requirements-dev.txt && cp .env.example .env
uvicorn app.main:app --reload   # http://localhost:8000/docs, демо: demo@zapas.kz / demo1234
pytest -q
```
Фронтенд подключается к бэкенду переменными `VITE_API_MODE=real` и `VITE_API_URL=http://localhost:8000/api/v1`, подробности в [frontend/README.md](frontend/README.md).

## Запуск в Docker
```bash
docker compose up --build
```
Фронтенд http://localhost:8080 (вход по умолчанию `demo@zapas.kz` / `demo1234`), документация API http://localhost:8000/docs. Данные бэкенда хранятся в volume `backend-data`; сбросить сид: `docker compose down -v`.
